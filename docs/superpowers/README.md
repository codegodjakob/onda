# Archiv — historische Etappen-Pläne

Dieser Ordner ist ein Archiv. Er enthält die Spezifikationen, Pläne und
Arbeitsprotokolle der abgeschlossenen Etappen (Juli 2026). Nichts hierin
beschreibt den aktuellen Zustand des Systems.

Für den aktuellen Stand gelten:

- `CONTEXT.md` im Wurzelverzeichnis — Begriffe und gebaute Architektur
- `docs/ONDA-SYSTEM.md` — das ganze System erklärt
- `node evals/run-fertigzustand.mjs` (aus `app/`) — frischer Messstand

Zahlen, Testergebnisse und Zusagen in diesen Dokumenten sind Momentaufnahmen
ihrer Entstehungszeit und werden nicht mehr gepflegt (Befund 6 der
Systemanalyse vom 4. August 2026, Issue #18).
