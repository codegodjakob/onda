# Lauf-Tor mit Lauf-Journal — Umsetzungsplan (Issue #12)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ein Pflicht-Tor (`lauf-tor.mjs`) vor `agent-gateway.runTask`, das Kanal-Sperre (synchron vor dem ersten await), Signatur-Prüfung, Verbrauchsbuchung und ein persistentes Lauf-Journal selbst besorgt; die vier Kanäle in `workspace.js` (Interview, Chat, Hinweis, Erweiterung) laufen nur noch durch dieses Tor, und ein Rückwachs-Wächter-Test macht einen Kanal ohne Tor unschreibbar.

**Architecture:** Zwei neue Module nach dem bestehenden Muster „reines Modell + dünne Verdrahtung": `lauf-journal.mjs` (pur: Journalform, Deckel/Verdichtung, stand-Feld, Signatur-Nachschlag, Invarianten-Prüfung) und `lauf-tor.mjs` (Sperren-Register + `fuehreLaufAus`, das einem Lauf-Callback ein bewachtes `runTask` aushändigt — der einzige Weg zum Gateway). Das Gateway behält die Verbrauchsbuchung (eine Wahrheit); das Tor journalisiert je Lauf Tokens/Kosten/Ergebnis. Das Journal liegt als eigener Bereich `laufJournal` **in data.json** (Entscheid der offenen Designfrage, Begründung in Task 4).

**Tech Stack:** Vanilla ES-Module, `node --test` (node:test + assert), esbuild-Bundle, Playwright-Smokes gegen `http://127.0.0.1:4173`.

Vertrag von `fuehreLaufAus` (der Kern des Pakets):
1. **Kanal-Sperre SYNCHRON vor jedem await**: ist der Kanal gesperrt → `{ gestartet: false, grund: 'lauf-aktiv' }`, sonst Sperre setzen, bevor `laufFn` läuft. `finally` gibt sie IMMER frei.
2. **Signatur-Prüfung**: bei `einmalJeSignatur && signatur === letzteBezahlteSignatur(journal, kanal)` → `{ gestartet: false, grund: 'unveraendert' }` — geprüft VOR der Sperre, synchron.
3. `laufFn({ runTask })` — das übergebene `runTask` ist der EINZIGE Weg zum Gateway: es wirft, wenn der Lauf beendet ist (verwaiste Referenz), summiert je Aufruf Tokens/Kosten in den Eintrag (auch aus Fehlern, Task 2) und delegiert an das Gateway (das weiter selbst bucht — eine Buchungswahrheit).
4. **Journal**: NUR bezahlte Läufe (mindestens ein runTask-Aufruf) landen im Journal. Ergebnis-Bewertung aus dem Rückgabewert von `laufFn`: `erfolg === false` → 'fehler'; `Array.isArray(uebernommen)` → leer: 'verworfen', sonst 'geliefert' (+ Zahlen geliefert/uebernommen/verworfen); sonst → 'geliefert'. Wirft `laufFn` → 'fehler', `fuehreLaufAus` wirft selbst NIE, sondern gibt `{ gestartet: true, erfolg: false, fehler: typ }` zurück.
5. Nach jedem journalisierten Lauf: `hooks.persist()`.

```js
// Skizze des Kerns (Implementierung in Step 3):
export async function fuehreLaufAus(beschreibung, laufFn) {
  const { kanal, ausloeser = null, signatur = null, einmalJeSignatur = false } = beschreibung || {}
  if (!KANAELE.includes(kanal)) throw new Error('Lauf-Tor: unbekannter Kanal: ' + kanal)
  if (typeof laufFn !== 'function') throw new Error('Lauf-Tor: laufFn fehlt')
  if (sperren.has(kanal)) return { gestartet: false, grund: 'lauf-aktiv' }
  if (einmalJeSignatur && signatur && signatur === letzteBezahlteSignatur(journal(), kanal)) {
    return { gestartet: false, grund: 'unveraendert' }
  }
  sperren.add(kanal) // SYNCHRON — vor diesem Punkt gibt es kein await in dieser Funktion
  const eintrag = beginneLauf({ kanal, ausloeser, signatur, einmalJeSignatur, jetzt: Date.now() })
  let laufOffen = true
  let bezahlt = false
  const torRunTask = async (task, eingabe, optionen) => {
    if (!laufOffen) throw new Error('Lauf-Tor: runTask nach Laufende — Kanal ' + kanal)
    bezahlt = true
    eintrag.tasks.push(task)
    if (!eintrag.stand) eintrag.stand = baueStand(task)
    try {
      const ergebnis = await gatewayRunTask(task, eingabe, optionen)
      verbucheImEintrag(eintrag, task, ergebnis.usage)
      return ergebnis
    } catch (fehler) {
      if (fehler && fehler.usage) verbucheImEintrag(eintrag, task, fehler.usage)
      throw fehler
    }
  }
  try {
    const ergebnis = await laufFn({ runTask: torRunTask })
    if (bezahlt) schliesseLauf(journal(), eintrag, bewerteLaufErgebnis(ergebnis), Date.now())
    return ergebnis
  } catch (fehler) {
    if (bezahlt) schliesseLauf(journal(), eintrag, { ergebnis: 'fehler', fehlerTyp: fehler?.typ || 'unbekannt' }, Date.now())
    return { gestartet: true, erfolg: false, fehler: fehler?.typ || 'unbekannt' }
  } finally {
    laufOffen = false
    sperren.delete(kanal)
    if (bezahlt && hooks.persist) hooks.persist()
  }
}
```
