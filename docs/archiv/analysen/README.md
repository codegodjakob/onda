# Systemanalysen

Diese Dateien sind datierte Analyse-Snapshots und Entwurfsrohmaterial. Sie erklären, welche
Lücken am jeweiligen Tag sichtbar waren; sie sind **kein aktueller Backlog** und keine zweite
Quelle für den Produktstand.

Maßgeblich für den heutigen Zustand sind:

1. `docs/VISION-GEGEN-GEBAUTES.md` für das Zielbild,
2. `docs/ONDA-SYSTEM.md` für die gebaute Architektur,
3. `app/evals/v2-fertigzustand.json` für die beobachtbaren Abnahmekriterien,
4. `app/evals/results/fertigzustand-latest.json` für den letzten frischen Beleg.

Offene Fragen oder Formulierungen wie „noch nicht gebaut“ in einem Analyse-Snapshot beziehen
sich ausschließlich auf dessen Datum. Eine Umsetzung gilt erst dann als vorhanden, wenn der
aktuelle Eval-Katalog sie prüft und der Fertigzustandsrunner sie im selben Lauf belegt.
