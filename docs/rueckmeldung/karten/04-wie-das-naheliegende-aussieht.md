# Wie das Naheliegende aussieht — und wie nicht

Type: prototype
Status: open

## Question

Wie verhindert man, dass die Erweiterungen das Erwartbare ausspucken?

Aus dem Abstract: *„Das System ist sich selbst bewusst, dass es eine AI ist, und
achtet darauf, nicht nur die Anmerkungen zu machen und Ideen zu beflügeln, die die
Wahrscheinlichsten sind."* Im Code gibt es dazu heute keinen Ansatzpunkt.

Das ist im Kopf nicht entscheidbar. Man muss sehen, wie beides aussieht:

1. An einem echten Text (etwa dem Calm-Technology-Beispiel oder einem von Jakobs
   Texten) Erweiterungen erzeugen — ohne jede Vorkehrung.
2. Dieselbe Aufgabe mit Vorkehrungen: ausdrücklicher Auftrag gegen das
   Naheliegende; mehrere Vorschläge erzeugen und die ähnlichsten verwerfen; ein
   zweiter Durchgang, der das Erwartbare aussortiert.
3. Nebeneinanderlegen. Jakob sagt, was er als naheliegend erkennt.

Erst daran zeigt sich, ob der Unterschied überhaupt sichtbar ist — und ob eine der
Vorkehrungen ihn erzeugt oder nur die Kosten verdoppelt.

**Antwort ist:** die Gegenüberstellung als Artefakt, plus eine Aussage, welche
Vorkehrung wirkt und welche nicht. Ein ehrliches „keine davon wirkt" ist ein
gültiges Ergebnis.
