# Rückmeldungs-Karten

Jakobs Karten zur Frage, **wie Onda Rückmeldung gibt** — entstanden am 04.08.2026,
bis dahin unversioniert in `.scratch/rueckmeldung/`. Versioniert mit Issue
[#17](https://github.com/codegodjakob/onda/issues/17) (Befund 4 der Systemanalyse
2026-08-04: externe Varietät erreicht das System nicht, wenn seine wichtigste
externe Quelle außerhalb der Versionskontrolle liegt).

## Die Regel

**Was der Eval-Katalog als Quelle zitiert, ist versioniert.** Der Katalog
`app/evals/v2-fertigzustand.json` zitiert diese Karten 15-mal als
„Rückmeldungs-Karte 04.08.2026: …" — eine Messlatte darf nicht auf Material
stehen, das ein einzelner Rechner verlieren kann. Wer künftig eine neue Quelle in
den Eval-Katalog schreibt, legt sie zuerst hier im Repo ab.
