Card: die ruhige Standard-Inhaltsfläche — weiß auf Papier, Haarlinie, keine Schatten im Ruhezustand.

```jsx
<Card title="Quartalsbericht" subtitle="Vor 2 Stunden bearbeitet" actions={<IconButton label="Mehr">…</IconButton>} interactive onClick={open}>
  <p>Inhalt</p>
</Card>
```

`interactive` nur wenn die ganze Karte klickbar ist. `padding="none"` für Listen/Tabellen in der Karte.
