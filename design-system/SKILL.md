Read the readme.md file within this skill, and explore the other available files.
If creating visual artifacts (slides, mocks, throwaway prototypes, etc), copy assets out and create static HTML files for the user to view. If working on production code, you can copy assets and read the rules here to become an expert in designing with this brand.
If the user invokes this skill without any other guidance, ask them what they want to build or design, ask some questions, and act as an expert designer who outputs HTML artifacts _or_ production code, depending on the need.

Key facts: link `styles.css` for all tokens (light default, `data-theme="dark"`; **ein** Akzent — Sky `#8db2c9`, gedämpft, keine Varianten, **keine Statusfarben** — Zustände neutral, Rot nur für Fehler/Löschen); ABC Diatype lokal via `@font-face` (`tokens/fonts.css`, Dateien in `assets/fonts/`) — keine Mono, Zahlen mit `tabular-nums`, **exakt vier Größen-Token: `--text-xs` 12 / `--text-base` 15 / `--text-xl` 21 / `--text-4xl` 40** und drei Gewichte (400/500/700) — Zwischenstufen existieren nicht; max. zwei Größen und zwei Textfarben pro Element; der Aura-Verlauf ist der KI-Präsenz vorbehalten; Radien: nur zwei — Controls sind Pillen (Buttons 32/40/48, Felder 40), Flächen 24px; Fokus = weicher Halo `--shadow-focus`, keine Outline; Trennlinien sparsam, Bereiche durch Flächen + Abstand trennen; Lucide icons, stroke 1.75; copy is calm, minimal, sentence case, no emoji. Components live in `components/*/` (Button, IconButton, Input, Textarea, Select, Checkbox, Radio, Switch, Card, Badge, Tag, Avatar, Icon, Dialog, Toast, Tooltip, Tabs, Aura, Bubble, Composer, Annotation, Mark, Correction, Insertion, Rewrite, Slot, Region). Symbole immer über `Icon` (Lucide-Pfade, 24er-Raster) — nie eigene SVG-Glyphen zeichnen. Anmerkungen des Agenten: Arten in `components/annotation/kinds.js`; die Darstellungsform folgt der Natur der Anmerkung — Korrektur am Wort (`Correction`), Umschreibung im Text (`Rewrite`), Einfügemarke (`Insertion`), Zielplatz (`Slot`), Bereich (`Region`), Quellen- oder Sammelkarte am Rand (`Annotation`), Meinung als Dialog (`Bubble`).. Reference screens: `ui_kits/writing-tool/index.html`.
