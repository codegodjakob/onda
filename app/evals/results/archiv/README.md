# Archiv — eingefrorene Etappen-Ergebnisse

Die Dateien in diesem Ordner sind historische Messstände der Etappen A bis D2
(Juli 2026). Sie beschreiben den Maßstab und den Stand von damals — nicht den
heutigen. Ihre 5,0-Werte konkurrieren nicht mit dem aktuellen Ergebnis.

Der aktuelle Stand liegt eine Ebene höher in `../fertigzustand-latest.json` und
wird frisch gemessen mit:

```
cd app && node evals/run-fertigzustand.mjs
```

Hintergrund: Befund 6 der Systemanalyse vom 4. August 2026 — alte Ergebnisdateien
lagen als konkurrierende Wahrheit neben dem frischen Lauf (Issue #18; die
Entwertung ist auch Teil von Issue #15).
